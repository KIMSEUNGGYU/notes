# Route 53과 DNS

> 한 줄 요약: **도메인을 발급하고 관리해주는 서비스.** 전문 용어로는 DNS(Domain Name System).

## DNS란

도메인이 없던 시절엔 특정 컴퓨터와 통신하려면 IP 주소를 직접 썼다. IP는 숫자라 사람이 외우기 불편하다.

그렇다고 컴퓨터더러 문자를 쓰라고 할 수도 없다 — 컴퓨터는 숫자가 처리하기 쉽다. 그래서 **IP는 그대로 두고, 사람은 문자로 관리하되, 그 사이를 변환해주는 시스템**을 만들었다. 그게 DNS다.

```
사용자가 입력          DNS 조회              실제 통신
admin.example.com  →  13.125.x.x 반환  →  그 IP로 요청
```

## 왜 도메인이 필수인가 — HTTPS

프론트엔드도 백엔드도 IP가 아니라 도메인으로 통신한다. 이유가 여럿 있지만 결정적인 건 **HTTPS**다.

**IP 주소에는 HTTPS를 적용할 수 없다.** 인증서는 도메인을 보증하는 문서라(→ [ACM 인증서](./03-acm)), 보증할 도메인이 없으면 인증서를 발급받을 수 없다. 서비스를 운영하려면 도메인이 사실상 필수인 이유다.

기억하기 쉽다는 건 부수적인 이점이고, HTTPS가 본질적인 제약이다.
