# 시작하기

## 왜 이 문서를 만들었나요?

개념은 글로 정리하면 깔끔하지만, 실제로 도구를 도입하고 코드에 녹이는 과정은 그렇지 않습니다. 문서에 없는 함정에 빠지고, 예상과 다르게 동작하고, 한참 헤맨 뒤에야 원인을 찾습니다.

이 문서는 그 **삽질의 기록**입니다. AI 도구를 실전에 적용하면서 겪은 시행착오와, 결국 어떻게 해결했는지를 남깁니다.

정리된 개념보다 **"그래서 실제로 어떻게 됐는지"** 에 집중합니다.

## 무엇을 다루나요?

- **Claude Code 실전** — 스킬·플러그인·서브에이전트·하네스로 AI 코딩 워크플로우를 구축한 기록
- **프롬프트 & 컨텍스트** — 프롬프트 설계와 컨텍스트 엔지니어링에서 효과가 있었던 것과 없었던 것
- **LLM 연동** — AI SDK 스트리밍, 구조화 출력, MCP 연동을 붙이며 겪은 문제들

> 각 주제는 순차적으로 채워집니다. 사이드바의 *(추가예정)* 항목이 작성 예정 목록입니다.
